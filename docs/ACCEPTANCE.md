## 公开限制与后续维护

- 个人规模原子 JSON 工作区，不是无限容量平台；当前 RPC 上限 5 MB，本地 localStorage 有浏览器配额。后续扩大数据量需迁移 IndexedDB/逐实体增量同步。
- 跨设备同时改不同对象也可能产生整体冲突；提供明确选择与导出，不做静默覆盖。导入同 ID 保留当前版，不能自动合并同一条记录的两个文本版本。
- 本机模式与云端账号分开，不会自动上传私人本机数据。用户主动导出/导入迁移。
- JSON 导入没有自动恢复活动计时器，避免假装可判断离开期间一直学习。请先结束计时再备份导入。
- 账号登出会清除该账号的本机工作区缓存；尚未同步时先提示备份/放弃。云端服务身份恢复、邮件配额和自动备份必须由项目所有者配置并验证。
- 存在真实外部前提，所以不能将此交付称为“所有云端功能已上线且可长期无维护”。上线所需最少操作见 START_HERE.md。
